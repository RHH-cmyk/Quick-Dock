# Quick Dock

Taskbar island that shows a folder grid on hover, with file thumbnails and the Explorer context menu.

## Features
- Displays a customizable taskbar island.
- Shows files in a folder grid when hovered.
- Displays file thumbnails.
- Supports the Windows Explorer context menu.
- Allows customization of the folder path, position, dimensions, columns, and colors.

## Usage
Configure the folder path and appearance in the mod's settings.
Hover over the island to display the folder grid.
Click a file to open it, or right-click to access the Explorer context menu.
*/
